# ChomLisp
## Overview

ChomLisp is a lightweight Lisp interpreter implemented in C++. It is designed to parse, evaluate, and execute Lisp-like expressions efficiently.

## Features

- **Lexer**: Tokenizes the input Lisp code into meaningful symbols.
- **Parser**: Converts tokens into an abstract syntax tree (AST) for evaluation.
- **Evaluator**: Executes the AST and returns the result of the Lisp expressions.

## File Descriptions

### `lexer.cpp`
Handles lexical analysis by breaking down the input Lisp code into tokens. It identifies keywords, symbols, numbers, and other components necessary for parsing.

### `parser.cpp`
Processes the tokens generated by the lexer and constructs an abstract syntax tree (AST). This tree represents the hierarchical structure of the Lisp code.

### `evalu.cpp`
Evaluates the abstract syntax tree (AST) generated by the parser. It executes the Lisp expressions and returns the computed results.

## Getting Started

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/ChomLisp.git
    cd ChomLisp
    ```

2. Build the project:
    ```bash
    g++ lexer.cpp parser.cpp evalu.cpp -o chomlisp
    ```

3. Run the interpreter:
    ```bash
    ./chomlisp
    ```

## Example Usage

Input:
```lisp
(+ 1 2 3)
```

Output:
```
6
```
